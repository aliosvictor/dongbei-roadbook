**地图与时间表怎么读**

- <span class="stop-tag row-planned">蓝色 · 主拍</span> 本日计划重点拍摄，仍以开放、通行和合法停车条件为前提。
- <span class="stop-tag row-optional">紫色 · 选停 / 备选</span> 按需补给、顺路短拍或满足条件后的替换点；可跳过，不是必到清单。地图使用紫色空心圆。
- <span class="stop-tag row-logistics">橄榄色 · 住宿 / 换乘</span> 执行所选方案需要衔接的住宿、停车换乘或入口；实际住宿用已确认的订单地址。
- <span class="stop-tag row-reference">灰色 · 途经参照</span> 只帮助判断方向或估算市区里程，不要求停车、进镇或游览。
- <span class="stop-tag row-drive">砖红色 · 行车</span> 对应地图自驾道路和整段高德路线链接，不表示禁飞或风险等级。
- <span class="stop-tag row-rest">中性底色 · 休息 / 准备</span> 保留用餐、休息和装车等安排，不等于可跳过的途经点。

地图点位、时间行标签与导航地名使用同一套用途颜色，与 S / A / B 摄影等级无关。时间行表示这段时间做什么，导航链接表示落点的用途：主拍时段也可能导航到橄榄色的停车换乘点。同一地点的住宿与选拍按各自用途区分，正文说明使用中性文字，不随禁飞状态改色。

休息、用餐和安全余量要保留，具体补给地点可以替换；选停时间是预留窗口，不是到点必须停车。整段导航中的道路方向控制点也不等于停车指令。

砖红线为 {{< var route-checked >}} 高德道路快照；园内景交和未核实支线不画自驾线。地图点位不是停车许可；准确入口、可停车位置与还车门店仍按逐日说明核实。

**状态另看短标签**：<span class="status-tag status-no-fly">禁飞</span> 红色表示本路书按禁飞执行，不凭 DJI 解禁或现场猜测起飞，除非事先取得可核验的书面批准；<span class="status-tag status-check">待核验</span> 琥珀色提示出行前核对天气、通行或开放等条件；<span class="status-tag status-check">航拍待核验</span> 表示起飞前同时核验 UOM 与管理方规则。
