**地图与时间表怎么读**

- <span class="stop-tag row-planned">蓝色 · 主拍</span> 本日计划重点拍摄，仍以开放、通行和合法停车条件为前提。
- <span class="stop-tag row-optional">紫色 · 选停 / 备选</span> 按需补给、顺路短拍或满足条件后的替换点；可跳过，不是必到清单。地图使用紫色空心圆。
- <span class="stop-tag row-logistics">橄榄色 · 住宿 / 换乘</span> 执行所选方案需要衔接的住宿、停车换乘或入口；实际住宿用已确认的订单地址。
- <span class="stop-tag row-drive">灰色 · 途经参照</span> 只帮助判断方向或估算市区里程，不要求停车、进镇或游览。

颜色按当天用途区分，与 S / A / B 摄影等级无关。休息、用餐和安全余量要保留，具体补给地点可以替换；选停时间是预留窗口，不是到点必须停车。整段导航中的道路方向控制点也不等于停车指令。

砖红线为 {{< var route-checked >}} 高德道路快照；园内景交和未核实支线不画自驾线。地图点位不是停车许可；准确入口、可停车位置与还车门店仍按逐日说明核实。
